# AGENTS.md

Guidance for agents working in this repository.

## Agent skills

### Issue tracker

Issues and specs live as GitHub issues in `mentho7/gloam-cn`, managed with the `gh` CLI. See `docs/agents/issue-tracker.md`.

### Triage labels

Five canonical triage roles (`needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`) plus the wayfinder exploration labels. See `docs/agents/triage-labels.md`.

### Domain docs

single-context — one root `GLOSSARY.md` and one `docs/adr/` for the whole repo. See `docs/agents/domain.md`.
